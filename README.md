# Jogo da forca (Python)

Jogo da forca no terminal para duas pessoas: o desafiante escolhe a palavra e o competidor tenta adivinhar.
São 6 erros até a forca fechar. Cada partida fica registrada no arquivo `historico`. Projeto de estudo.

## Rodar

```bash
python game.py
```

Feito para o terminal do Windows (limpa a tela com `cls`).
